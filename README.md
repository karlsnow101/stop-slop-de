# stop-slop-de

Deutsche Fassung des Claude-Skills [stop-slop](https://github.com/hardikpandya/stop-slop) von Hardik Pandya (MIT-Lizenz, Original-Commit 8da1f03). Übersetzung und deutsche Entsprechungen sind eine eigene Bearbeitung.

## Installieren

1. [stop-slop-de.zip herunterladen](https://github.com/karlsnow101/stop-slop-de/raw/main/stop-slop-de.zip)
2. In claude.ai: Customize → Skills → „+“ → „Create skill“ → „Upload a skill“ und die ZIP auswählen.

Der Ordner `stop-slop-de/` enthält dieselben Dateien entpackt.
